# Sneakers E-commerce Product Page

An interactive, responsive product showcase page built to simulate modern e-commerce user experiences, state management, and gallery views.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Next.js 
* **Language:** TypeScript
* **Styling & UI:** Tailwind CSS
* **Deployment:** Vercel

---

## Core Features

* **Interactive Lightbox Gallery:** Desktop full-screen modal gallery with main image viewing, thumbnail switching, and next/previous controls.
* **Dynamic Cart Management:** Client-side state handling item additions, real-time quantity adjustments, price calculations, and item removals.
* **Responsive Mobile Navigation:** Mobile-optimized slide-out navigation menu and image carousel touch support.
* **Interactive Quantity Counter:** Increment and decrement selectors with state bounds to prevent invalid selections.
